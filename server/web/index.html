Консоль

Команды выполняет игра выбранного игрока. Встроенные: gold N, give ID N, heal, tgm, tcl, tm, tai, coc Место, tp Имя, avatar save, equip ID, kill ID. Остальное — как консоль ПК (player.additem …, player.setav …). Стрелки ↑/↓ — прошлые команды.

Сервер

«Начать кампанию заново» стирает мир сервера (квесты, убитых, сундуки, двери, спутников, сохранения кампании), старое уходит в папку old_campaigns. После этого сервер выключается — запусти его снова. Персонажам на консолях нужна новая игра: старые сохранения кампании станут личными.

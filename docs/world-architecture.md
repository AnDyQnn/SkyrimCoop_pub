# Глобальный онлайн-мир: архитектура (03.10.2026)

Сейчас (как Skyrim Together): у каждой консоли свой мир, сервер только пересылает события между
игроками сессии. Подходит для кампании вдвоём, не годится для постоянного мира.

Новая модель — **сервер владеет миром**, консоль показывает его и присылает действия.

## 1. Сервер = мир
Сервер держит постоянную базу мира (на диске, переживает перезапуски):
| Что | Хранится | Сбрасывается |
|---|---|---|
| NPC: жив/мёртв, где лежит труп | по FormID | обычные — никогда (как ваниль без респауна); враги данжей, драконы, мировые боссы — по таймеру |
| Содержимое сундуков, трупов, предметы на земле | дельты к ванили | вместе со своей ячейкой-данжем |
| Двери, замки, рычаги, ловушки | открыто / закрыто / вскрыто | с ячейкой-данжем |
| Квесты | стадии **гильдии** | никогда |
| Время и погода мира | одно на сервер | — |
| **Уровень мира** | = уровень самого сильного игрока онлайн | живой |
| Игрок (аватар) | уровень, навыки, перки, инвентарь, позиция | — |

## 2. Консоль = окно в мир
- Каждый грузится и перемещается **сам**: двери, телепорты, быстрое перемещение, своя загрузка.
- **Вошёл в ячейку** → консоль спрашивает сервер «что тут?» → сервер присылает состояние ячейки
  (кто мёртв, что вынуто из сундуков, какие двери открыты) → консоль приводит свою ячейку к нему.
- **Сделал что-то** (убил, взял, открыл, продвинул квест) → действие уходит на сервер → сервер
  записывает и рассылает всем, у кого эта ячейка загружена.
- Свой сейв консоли в онлайне — только кэш. Правда — на сервере.

## 3. Гильдия (вместо клана, проще)
- Гильдия = общий прогресс квестов и общий сундук. Игрок без гильдии — гильдия из одного.
- Стадию квеста двигает любой член — она у всей гильдии. Награда каждому, кто онлайн.
- Уникальные квестовые вещи — одна на мир (мир общий), достаётся тому, кто взял.

## 4. Уровень мира
- Все враги, лут и награды масштабируются по **самому высокому уровню игрока онлайн**.
- Слабому игроку идти с сильным; соло — тоже на этом уровне (решение: не делать «легко»).

## 5. Перезапускаемые точки (гринд)
Данжи с боссами, логова драконов, мировые боссы Ша'джары: сервер считает таймер (3 игровых дня),
при следующем входе в ячейку — свежие враги, лут, дракон с душой. Остальной мир не сбрасывается.

## 6. Что меняется в коде
| Слой | Сейчас | Будет |
|---|---|---|
| Сервер (Python) | пересылка + `killed`, зоны, квесты клана | **WorldStore**: база ячеек (смерти, контейнеры, двери, таймеры сброса), гильдии, уровень мира |
| Протокол | события «я сделал» → всем | + `CELL_ENTER` → `CELL_STATE`; действия → сервер → подписчикам ячейки |
| Модуль | применяет события от других | + приводит ячейку к состоянию сервера при входе; сообщает о своих действиях |

## 7. Порядок
1. ✅ Меню без паузы (готово, собрано).
2. WorldStore на сервере + CELL_ENTER/CELL_STATE: **смерти NPC** (уже частично: `killed`).
3. Контейнеры, трупы, предметы — дельты.
4. Двери, замки.
5. Гильдии (переименование + общий прогресс, уже частично в quests.cpp).
6. Уровень мира.
7. Сброс данжей/драконов по таймеру.
8. Смерть игрока — без перезагрузки сейва (решение 03.10):
   - внутри подземелья / любого помещения → воскрешение у **двери, через которую вошёл** (последняя дверь);
   - в открытом мире → в **ближайшем городе** (Вайтран, Солитьюд, Виндхельм, Рифтен, Маркарт, Морфал,
     Данстар, Винтерхолд, Фолкрит, Рейвен-Рок);
   - здоровье полное, вещи остаются при тебе; штраф за смерть — обсудим (по умолчанию нет).
